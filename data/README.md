# Data

The datasets are not stored in this repository. Download them from the original sources and merge them into `Dataset.csv` with the columns `text, sentiment_label, aspect, label_source, source, domain`.

| Source | Rows | Labels | Link |
|---|---|---|---|
| University of Oregon RateMyProfessors reviews | 37,437 | Derived from star ratings | [Kaggle](https://www.kaggle.com/datasets/eastonsell/university-of-oregon-ratemyprofessors) |
| EduRABSA (combined 6.5k) | 6,441 | Human-annotated | [GitHub](https://github.com/yhua219/edurabsa_dataset_and_annotation_tool) |
| Sentiment Analysis – Faculty Evaluation | 638 | Provided with the dataset | [Kaggle](https://www.kaggle.com/c/sentiment-analysis-faculty-evaluation) |

The merged dataset has **44,516 comments**: 27,541 positive, 12,165 negative and 4,810 neutral.
